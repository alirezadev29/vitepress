# مدیریت نسخه با Git

**Git** یک سیستم کنترل نسخه توزیع‌شده است که تاریخچه تغییرات را ثبت می‌کند. 

## ۱. Git در برابر GitHub/GitLab
- **Git**: نرم‌افزاری روی سیستم شماست که تغییرات را ثبت می‌کند.
- **GitHub/GitLab**: سروری در اینترنت است که کدهای شما را میزبانی می‌کند و ابزارهایی برای همکاری تیمی فراهم می‌کند.

## ۲. چرخه کاری روزمره در Git
این ۴ دستور را در ۹۰٪ مواقع استفاده خواهید کرد:

```bash
# 1. دیدن وضعیت فایل‌ها
git status

# 2. اضافه کردن فایل‌ها به مرحله Staging
git add .

# 3. ثبت تغییرات با یک پیام معنادار
git commit -m "feat: add navigation bar"

# 4. ارسال به سرور
git push origin main
