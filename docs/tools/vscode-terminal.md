# ابزارهای پایه: VS Code و ترمینال

یک توسعه‌دهنده حرفه‌ای زمان زیادی را در ترمینال و ویرایشگر کد می‌گذراند. تسلط بر این دو ابزار سرعت کار شما را چند برابر می‌کند.

## ۱. تسلط بر VS Code
VS Code فقط یک ویرایشگر متن نیست؛ بلکه یک محیط توسعه یکپارچه (IDE) سبک است.

### میانبرهای طلایی (Keyboard Shortcuts)
یادگیری این میانبرها شما را از ماوس بی‌نیاز می‌کند:
- `Ctrl + P`: جستجوی سریع فایل‌ها در پروژه.
- `Ctrl + Shift + P`: باز کردن Command Palette (برای اجرای هر دستوری در VS Code).
- `Ctrl + B`: مخفی/نمایان کردن نوار کناری (Sidebar).
- `Alt + Up/Down`: جابجایی خطوط کد.
- `Shift + Alt + Down`: کپی کردن خط جاری به پایین.
- `Ctrl + /`: کامنت/آنکامنت کردن خطوط.

### افزونه‌های ضروری برای فرانت‌اند
| افزونه | کاربرد |
| :--- | :--- |
| **Prettier** | قالب‌بندی خودکار و یکدست‌سازی کدها. |
| **ESLint** | پیدا کردن خطاهای منطقی و سینتکسی در جاوااسکریپت. |
| **Live Server** | اجرای سریع فایل‌های HTML با قابلیت Hot Reload. |
| **GitLens** | دیدن اینکه هر خط کد توسط چه کسی و در چه تاریخی نوشته شده (Blame). |
| **Error Lens** | نمایش خطاها دقیقاً در همان خط کد (نه در پایین صفحه). |

## ۲. ترمینال (خط فرمان)
ترمینال در واقع پوسته‌ای (Shell) برای ارتباط با هسته سیستم‌عامل (Kernel) است.

### دستورات پیشرفته‌تر
علاوه بر `cd` و `ls`، این دستورات را یاد بگیرید:
- `mkdir my-folder`: ساخت پوشه جدید.
- `touch index.html`: ساخت یک فایل خالی (در ویندوز: `echo "" > index.html`).
- `rm -rf folder`: حذف اجباری یک پوشه و محتویاتش. **⚠️ (بسیار مراقب باشید، بازگشت ندارد!)**
- `code .`: باز کردن پوشه فعلی در VS Code (بسیار کاربردی).
- `pwd`: نمایش مسیر فعلی (Print Working Directory).

### دستورات مربوط به Node.js و npm
در پروژه‌های مدرن وب، ترمینال حکم کارگاه اصلی را دارد:
```bash
# نصب پکیج‌ها بر اساس فایل package.json
npm install

# اجرای اسکریپت‌های پروژه (مثل بالا آوردن سرور توسعه)
npm run docs:dev

# نصب یک کتابخانه به عنوان وابستگی اصلی
npm install axios

# نصب یک ابزار فقط برای محیط توسعه
npm install -D typescript

# بررسی نسخه‌های نصب شده
node -v
npm -v
