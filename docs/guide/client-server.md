# نحوه کار وب (Client/Server)

مبحث **نحوه عملکرد وب** شرح کلی از وقایعی ارائه می‌دهد که هنگام استفاده از یک مرورگر وب برای رفتن به یک صفحه وب رخ می‌دهد.

## تفاوت اینترنت (Internet) و وب (Web)
- **اینترنت:** یک شبکه جهانی از کامپیوترهاست (زیرساخت).
- **وب:** مجموعه‌ای از صفحات و منابع اطلاعاتی است که روی بستر اینترنت اجرا می‌شود (سرویس).

::: tip نکته
اینترنت مثل جاده است و وب مثل ماشین‌هایی که روی این جاده حرکت می‌کنند.
:::

## معماری کلاینت-سرور (Client-Server)
ارتباط در وب بر اساس این معماری انجام می‌شود:
1. **مرورگر (کلاینت):** آدرس `google.com` را درخواست می‌کند.
2. **مرورگر:** از طریق پروتکل HTTP یا HTTPS یک درخواست (Request) ارسال می‌کند.
3. **سرور:** درخواست را دریافت و پردازش می‌کند.
4. **سرور:** یک پاسخ (Response) شامل فایل‌های HTML/CSS به مرورگر می‌فرستد.
5. **مرورگر:** اطلاعات را پردازش کرده و صفحه را رندر (نمایش) می‌دهد.
