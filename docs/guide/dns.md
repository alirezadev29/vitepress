# سیستم DNS و آدرس‌دهی

در بخش قبلی کلیات را بررسی کردیم. حالا بدانیم پشت صحنه چه اتفاقاتی صورت می‌گیرد.

## ۱. ترجمه نام دامنه با استفاده از DNS
مرورگر برای اتصال به وب‌سایت، به آدرس IP سرور نیاز دارد. مرورگر ابتدا بررسی می‌کند که آیا رکورد DNS در حافظه کش (Cache) موجود است یا خیر. اگر موجود نباشد، از **DNS (Domain Name System)** برای تبدیل نام دامنه به آدرس IP استفاده می‌کند.

درواقع آدرس‌های واقعی وب، عبارت‌هایی که برای جست‌وجو استفاده می‌کنیم نیستند؛ بلکه اعداد خاصی هستند؛ مثلاً برای `google.com` آدرس IP به این صورت است: `142.251.142.206`

::: warning کش DNS
مرورگر و سیستم‌عامل شما از یک حافظه کش برای ذخیره این IPها استفاده می‌کنند تا در دفعات بعدی سریع‌تر سایت‌ها را باز کنند.
:::

## ۲. آدرس‌دهی و برقراری ارتباط
آدرس‌دهی IP، به دستگاه‌های موجود در یک شبکه، آدرس‌های منطقی اختصاص می‌دهد و بدین‌وسیله امکان شناسایی و دسترسی به آن‌ها را فراهم می‌سازد.

هنگامی که مرورگر درخواستی ارسال می‌کند، آدرس IP مقصد به مسیریاب‌ها (روترها) کمک می‌کند تا بسته‌های داده را به سمت سرور صحیح هدایت کنند. بدون آدرس‌دهی IP، دستگاه‌ها فاقد اطلاعات لازم برای مسیریابی داده‌ها خواهند بود. در نهایت، مرورگر اتصال خود را با سرور برقرار می‌کند.
