# رندر کردن صفحه وب

مرورگر سند دریافت‌شده را تجزیه (Parse) می‌کند، چیدمان و موقعیت عناصر صفحه وب را محاسبه می‌نماید و در نهایت صفحه را روی نمایشگر رندر می‌کند تا کاربر بتواند آن را مشاهده کرده و با آن تعامل داشته باشد.

## بارگذاری منابع و تعاملات
مرورگر منابع تکمیلی نظیر فایل‌های CSS، JavaScript، تصاویر و فونت‌ها را که در حافظه کش موجود نیستند، بارگذاری می‌کند. سپس این منابع را پردازش می‌کند تا محتوا، استایل‌ها و قابلیت‌های تعاملی صفحه وب را نمایش دهد.

::: tip تعامل با صفحه
هنگامی که کاربران روی دکمه‌ها کلیک می‌کنند، فرم‌ها را ارسال می‌کنند یا در صفحات جابه‌جا می‌شوند، ممکن است کدهای جاوااسکریپت درخواست‌هایی را به سرور یا یک API ارسال کنند تا تبادل داده صورت گیرد. سرور این درخواست‌ها را پردازش کرده و داده‌ها یا محتوای به‌روزرسانی‌شده را بازمی‌گرداند؛ مرورگر نیز بر حسب نیاز، آن‌ها را نمایش می‌دهد.
:::
