این فایل برای استاد و هر توسعه‌دهنده‌ای است که بخواهد پروژه رو اجرا کنه. ظاهر این فایل باید بسیار تمیز و استاندارد باشه.

# مستندات جامع وب - پروژه کالج توربوفرانت ۶

- Node.js (نسخه ۱۸ یا بالاتر)
- npm (نسخه ۹ یا بالاتر)

## 🚀 نصب و اجرا

برای راه‌اندازی محیط توسعه (Development)، دستورات زیر را در ترمینال اجرا کنید:

```bash
# 1. کلون کردن مخزن
git clone https://igit.partcorp.ir/college/turbofront6/groups-v1/seyfi-shojaeian/session1-vitepress-docs.git

# 2. ورود به پوشه پروژه
cd session1-vitepress-docs

# 3. نصب پکیج‌ها
npm install

# 4. اجرای سرور لوکال
npm run docs:dev
